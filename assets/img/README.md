# assets/img

Drop real assets here. Nothing in this folder is required for the site to work today.

| File | Purpose | Notes |
|---|---|---|
| `favicon.svg` | Browser tab icon | Present. Minimal "NP" mark on `--ink`. Replace with your logo mark if you like. |
| `logo.svg` (or `.png`) | Org logo | Not present yet. See the root README → "Logo" for how to swap the text wordmark. |
| `portraits/<tag>.webp` | Player photos | Optional, square, ≥192×192. Real alt text required (gamertag + role). |
| `og.png` | Social share image | 1200×630. Then add `<meta property="og:image" content="https://YOUR-USERNAME.github.io/assets/img/og.png">` to each page. |
