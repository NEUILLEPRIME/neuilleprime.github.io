# NEUILLE PRIME (NP67) website

Static bilingual (EN/FR) site for the NEUILLE PRIME esports org. Full README written in M6.

## Placeholders

Every value to replace starts with `YOUR-`. Search the project for `YOUR-` to find them all.

| Placeholder | Lives in | Replace with |
|---|---|---|
| `YOUR-USERNAME` | all pages (`og:url`) | Your GitHub username |
| `YOUR-INVITE` | all pages (footer) | Discord invite code |
| `YOUR-HANDLE` | all pages (footer: X, Instagram) | X / Instagram handle |
| `YOUR-CHANNEL` | all pages (footer: Twitch, YouTube) | Twitch / YouTube channel |
