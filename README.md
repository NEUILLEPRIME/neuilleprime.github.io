# NEUILLE PRIME (NP67) website

Static bilingual (EN/FR) site for the NEUILLE PRIME esports org. Full README written in M6.

## Placeholders

Every value to replace starts with `YOUR-`. Search the project for `YOUR-` to find them all.

| Placeholder | Lives in | Replace with |
|---|---|---|
| `YOUR-USERNAME` | all pages (`og:url`) | Your GitHub username |
| `YOUR-INVITE` | all pages (footer) | Discord invite code |
| `YOUR-HANDLE` | all pages (footer: X, Instagram) | X / Instagram handle |
| `YOUR-CHANNEL` | all pages (footer: Twitch, YouTube) | Twitch / YouTube channel |
| `YOUR-EMAIL` | Home contact band, About contact (`mailto:YOUR-EMAIL@example.com`) | Contact email address |
| `YOUR-YEAR` | Home org card, About structure block | Founding year |
| `YOUR-TAG-1` … `YOUR-TAG-8` | Home roster rail (1–6), Roster page (all) | Player gamertags (also used as their X / Twitch handles on the Roster page): YOUR-TAG-1, YOUR-TAG-2, YOUR-TAG-3, YOUR-TAG-4, YOUR-TAG-5, YOUR-TAG-6, YOUR-TAG-7, YOUR-TAG-8 |
| `YOUR-COACH-RL`, `YOUR-COACH-LOL` | Roster page | Coach handles (Rocket League, League of Legends) |
| `YOUR-STAFF-1`, `YOUR-STAFF-2`, `YOUR-STAFF-3` | Roster page (staff) | Manager, media and operations staff names or handles |
